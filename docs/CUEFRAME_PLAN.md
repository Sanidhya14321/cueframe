## Repository findings

- Read `AGENTS.md`, `README.md`, `package.json`; inspected the requested `src/project`, `src/schemas`, `src/compositions`, `src/core`, `src/app` modules and their editor, persistence, MCP and render integrations.
- `Project` is canvas/fps/duration/background plus tracks; tracks contain text/image/video/shape/composition elements. Each composition references a registered clip and its schema-validated props, with its own `from` and duration.
- Multiple clips already play sequentially or overlap on tracks; `src/mcp/video-builder.ts` already places them. No separate sequence track is needed. Track zero paints on top; later elements within a track paint above earlier ones.
- `src/compositions/project/project-composition.tsx` uses Remotion Sequences; browser export and `src/render/render-project.ts` share this composition. Clip schemas, defaults, hand-written controls and scenes are registered separately; lazy scene loading also needs registration.
- `clip-timeline-editor.tsx` calls pure mutation functions directly; there is no serialized action union/reducer dispatcher. `use-undoable.ts` keeps snapshot history and groups gestures; clip/poster drafts autosave in localStorage. Picked blob URLs do not survive reloads.
- Clerk provider/proxy, custom auth screens, approval gates, API keys and OAuth protect agent/MCP/publishing. Neon/Drizzle stores sites and videos by owner; API routes and saved-video/site pages depend on these. There are no separate organization tables in the current schema.
- Existing `/mcp` uses the official SDK and account-backed catalog/video/site tools. `/api/agent` uses AI SDK/OpenRouter with fixed models; preserve validation/asset masking while replacing credentials and account checks.
- Missing capabilities: persistent uploaded media, revisioned actions/SSE, locks/comments, audio elements/ducking, source offsets for split videos, word-timed captions and item-local render error boundaries.

## Shared implementation decisions

- Add server-only `src/local/` for settings, storage, session protection, media and events; default to `~/cueframe/settings.json` and `projects/<safe-name>/{project.json,media/,out/}`. Keep secrets out of client responses/logs and restrict settings-file permissions.
- Generate one runtime token per app start; bootstrap it only to the local browser, protect reads of private data and all writes/MCP, validate browser Origin and Host, and explicitly support authenticated CLI requests without Origin. Bind dev, production, tests and launcher to `127.0.0.1` from step 2.
- Validate path containment and uploads, serialize writes per project, atomically replace JSON files, reject stale revisions and resync on reconnect. Browser and tools use one Zod action dispatcher around existing mutations; server enforces locks, including undo/reset/bulk writes.
- Preserve gesture history while making undo/redo revisioned server actions; agent-turn undo must preserve unrelated user edits. Import existing browser drafts without overwriting newer disk projects; persist uploaded files before saving references.
- Permit only MIT, Apache-2.0, ISC, BSD, CC0, MIT-0 or Unlicense for new copied code/assets; retain license texts and record URL, exact commit/version, files and modifications in `NOTICE.md`. The prompt's OFL font suggestion does not override this allowlist; do not import new OFL fonts without your explicit change to it.
